# WARBAND-NATIVE-OP-SAMURAI

<br>

**Test how far you can go as an overpowered samurai in Mount & Blade: Warband**

## TO DOWNLOAD
```
git clone https://github.com/1889-IENA/WARBAND-NATIVE-OP-SAMURAI.git
```

<br>

**Before starting the game you need to obtain these items from the cheat menu add them to your inventory then it is recommended to disable cheats before continuing**
